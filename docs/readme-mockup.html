XTLLM (eXpert-Tier LLM) is an experimental, text-only Vulkan inference engine for running very large mixture-of-experts models on consumer AMD GPUs. It keeps a model-specific working set in VRAM, a budgeted expert tier in system RAM, and the cold remainder on NVMe.

Status: Windows/RDNA2 research preview. Greedy text generation is working. Model weights are not included.

Why this exists

NVMe cold experts→Budgeted RAM→VRAM cache→Finite Vulkan kernels
BF16 host K/V supplies bounded long-context attention
  • One executable auto-detects four model families.
  • Live Vulkan memory-budget sizing selects a safe, model-specific cache.
  • Authoritative routing; no Q3, expert dropping, or TDR changes.

Quick start — Windows

git clone https://github.com/opktunme/XTLLM.git xtllm
cd xtllm
powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1

.\xtllm.cmd setup qwen36 --model-root D:\XTLLM-Models
.\xtllm.cmd chat qwen36

Safety boundaries

Finite submissions and I/O waits; no GPU busy-spin, unbounded shaders, hidden RAM tier, Q3 shortcut, router changes, or Windows TDR modifications.
